## Organisation
 
Chaque TP est rangé dans son propre dossier, nommé selon le numéro et le thème de la séance :
```
.

│   ├── main.py
│   └── README.md (optionnel, si le TP nécessite des explications spécifiques, etc)
├── tp02-nom_du_theme/
│   └── ...
└── README.md
```
 
Ce fichier sera complété au fil de l'année, à mesure que les TP sont ajoutés.

## Exécution
 
Chaque TP peut être lancé indépendamment depuis son dossier :
 
```bash
cd tp01-nom_du_theme
python main.py
```
 
Si un TP nécessite des dépendances particulières, un fichier `requirements.txt` sera ajouté dans le dossier correspondant.
